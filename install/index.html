Install

Set up RustDesk for your device

Your device is selected automatically. If it's wrong, choose the right one below.

JavaScript is needed to choose the right download. You can also get RustDesk from its official release page, then enter the values on the Key page.

Mac permissions

macOS asks for each permission separately. Keep clicking Configure until the pink panel disappears.

For each permission

  1. Click Configure in the pink panel.
  2. Click Open System Settings when macOS asks.
  3. Find RustDesk, turn it on, and enter your Mac password.
  4. If macOS offers Quit & Reopen, click it. RustDesk then asks for the next permission.

1. Screen Recording

Lets Jonathan see your screen. It's under Privacy & Security → Screen & System Audio Recording, or Screen Recording on older macOS versions.

2. Accessibility

Lets Jonathan move your mouse and type. It's under Privacy & Security → Accessibility.

3. Input Monitoring

Only needed if RustDesk asks. It's under Privacy & Security → Input Monitoring.

You're finished when the pink panel is gone and RustDesk shows Ready at the bottom.

Older Mac on Big Sur or Monterey?

If the latest version won't open, install RustDesk 1.3.9 for Intel Macs, then enter the values from the Key page in RustDesk's network settings.

Trouble connecting?

Run the connection check, then contact Jonathan at hello@jonathanellis.ca.
